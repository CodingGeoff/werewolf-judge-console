## 第 0 章 · 底层思维模型

任何"排列组合"都可以被压缩成三个可计算量。理性玩家不是靠记套路，而是靠**每回合重算这三个量**。

### 0.1 轮次表（Vote Count）

> 轮次 = 好人"还能出几个狼" vs 狼队"还能刀几个神/民"。

以 10 人标准局（3 狼 / 3 神 / 4 民，屠边，狼刀剩 1 民即算屠民胜）为例：

| 事件 | 好人轮次 | 狼队轮次 |
|---|---|---|
| 好人放逐 1 狼 | +1 | −1 |
| 好人放逐 1 民 | −1 | 0 |
| 好人放逐 1 神 | −2 | 0 |
| 女巫解药救 1 人（被刀者） | +1 | 0 |
| 女巫毒杀 1 狼 | +1 | 0 |
| 女巫毒杀 1 好人 | −2 | 0 |
| 猎人带走 1 狼 | +1 | 0 |
| 猎人带走 1 好人 | −2 | 0 |
| 狼人刀 1 神 | 0 | +1 |
| 狼人刀 1 民 | 0 | +1 |
| 狼人自刀（被救起） | 0 | 0 |
| 狼人自刀（未被救，倒牌） | 0 | −1（等价于好人出 1 狼） |

**关键推论 1（首夜开解药的轮次不变性）**
> 狼人自刀被女巫救起 → 轮次为 0，**好人并没有吃亏**。所以女巫首夜开解药"被骗"的担忧，在轮次上是伪命题。

**关键推论 2（女巫是轮次放大器）**
> 女巫一晚可以"救 1 + 毒 1" = 好人 **+2 轮**。这是全局唯一能一次追 2 轮的技能。所以**女巫的每一瓶药都是决定性的**，狼队的第一优先级永远是找女巫。

**关键推论 3（猎人是被动轮次）**
> 猎人的枪是"死一次换一次"，属于**负收益期望**（好人才用）。所以：
> - 猎人前期**必须藏**，因为一旦被确认身份，狼队会把猎人留到最后（深夜刀），猎人的追刀价值归零。
> - 猎人被首刀 → 狼队"免费"处理掉一张神牌且猎人无法开枪，等于好人纯亏 2 轮。

### 0.2 信息价值表（Information Value）

不同信息的好人确认度从低到高：

| 信息 | 确认度 | 说明 |
|---|---|---|
| 银水（女巫所救） | 弱 | 狼可自刀骗药，且女巫可能撒谎 |
| 金水（预言家所验） | 强 | 但前提是预言家为真 → **信息强度依赖信源强度** |
| 查杀 | 极强 | 但同样依赖信源；且"被发查杀"可能反向做低身份 |
| 死亡 | 强 | 白天死亡 = 被票（几乎必是好人）；夜里死亡 = 可能是狼自刀 |
| 行为/投票 | 强 | "发言会骗人，票型可能是假的，逻辑也可能是反的，但**行为不会**" |
| 死亡方式 | 极强 | 被刀 = 好人候选；被毒 = 女巫目标；被枪 = 猎人目标 |

> **信源强度链**：预言家查杀 > 预言家金水 > 女巫银水 > 平民投票
> **反驳链**：反向金水（悍跳狼发查杀给好人）→ 好人身份做高

### 0.3 期望值决策树（每一次开药、每一次刀人、每一次开枪）

```
决策 = argmax( P(正确) × 收益 − P(错误) × 代价 )

其中：
  收益 ≈ 该操作追回/保留的轮次
  代价 ≈ 错误操作造成的轮次损失 + 未来信息污染成本
  P(正确) 由「信息源强度 × 时间衰减」估算
```

**时间衰减原则**：信息越晚使用，价值越低。第 1 天的查验 = 100% 价值，第 3 天的查验 = 60% 价值（因为好人已被消耗、局面已定）。
→ 推论：**能早毒就早毒，能早验就早验，绝不囤药到最后一晚**。

## 第 1 章 · 板子与规则基线

### 1.1 9 人局

**配置 A（最常见，无警徽制/有警徽制并存）**
```
3 狼  |  预言家 · 女巫 · 猎人  |  3 民
```
- 胜利条件：屠边（杀光民或杀光神）
- 女巫首夜可自救（房规）
- 有/无警徽：见下方说明
- 若女巫不能自救 → 9 人配置神职过强，狼人需刀中女巫才算平衡

**配置 B（保守平衡版）**
```
3 狼  |  预言家 · 女巫 · 猎人  |  3 民   ← 女巫全程不能自救
```

**配置 C（民间/练习局）**
```
3 狼  |  预言家 · 女巫 · 白痴  |  3 民
```

### 1.2 10 人局

**配置 A（标准，最常用）**
```
3 狼  |  预言家 · 女巫 · 猎人  |  4 民
屠边，狼人刀剩 1 民即算屠民获胜
```

**配置 B（白痴局）**
```
3 狼  |  预言家 · 女巫 · 猎人 · 白痴  |  3 民
```

```

```

### 1.3 关键规则差异对照（开局必须确认的 12 项）

| # | 规则项 | 影响 |
|---|---|---|
| 1 | 是否有警徽 | 无警徽 → 预言家不能打警徽流，信息全靠自己留 |
| 2 | 单爆吞警徽 / 双爆吞警徽 | 决定狼人自爆是否吞掉警长竞选轮次 |
| 3 | 女巫可否自救 | 首夜可救 vs 全程不可救 |
| 4 | 女巫解药是否使用后不再告知刀口 | 影响女巫信息优势 |
| 5 | 猎人被毒能否开枪 | 部分网杀规则允许网杀外"被毒也能带" |
| 6 | 遗言规则 | 首夜死者是否有遗言；单死/多死是否有遗言 |
| 7 | 狼人自爆是否有遗言（指刀） | 影响狼人自爆的信息价值 |
| 8 | 屠边 vs 屠城 | 决定狼队目标（屠民 or 屠神） |
| 9 | 白痴算民还是算神 | 影响屠边判定 |
| 10 | 狼刀在先原则 | 夜里同归于尽时狼队优先获胜 |
| 11 | 平票处理 | 平票 PK 后再平票是否直接放逐 |
| 12 | 首刀/首验保护 | 是否影响第二局（网杀） |

> **理性玩家第一条铁律**：拿到牌先花 30 秒确认这 12 项。不同房规下"最优解"可以完全相反。

### 1.4 夜间行动顺序（标准预女猎）

```
第一夜：狼人 → 女巫 → 预言家 → 猎人(确认身份) → 白痴(确认身份)
其他夜：狼人 → 女巫 → 预言家
```
> **狼刀在先原则**：若夜里狼刀达成胜利条件（屠边），即使女巫随后毒死最后一只狼，**狼队仍然获胜**。

### 1.5 发言与警徽

- **警上发言**：顺序由报名顺序决定（多数平台按号码）。
- **警长权限**：安排发言顺序（警左/警右）、归票权、投票计 1.5 票、死亡时可移交/撕毁警徽。
- **警徽流**：预言家死后通过警徽传递验人结果的机制，是"防自爆吞信息"的核心设计。

## 第 2 章 · 局势判定：先分类，再决策

**每一回合开始前，先做三分类：**

### 分类 1：局型（决定整个游戏基调）

| 局型 | 特征 | 好人核心任务 | 狼队核心任务 |
|---|---|---|---|
| **对跳局** | 狼悍跳预言家，有真假预对跳 | 快速分辨真假 + 抗推 | 抢警徽 + 抗推真预 + 刀神 |
| **怂狼局** | 狼不悍跳，真预言家首验金水 | 压缩狼坑，稳推 | 藏身份、找神、熬到生推 |
| **双爆生推局** | 狼双爆吞警徽 + 刀死预言家 | 建立发言基线，逐个排坑 | 刀神、控制发言位、绑票 |

### 分类 2：轮次领先方

| 状态 | 判定 | 战略含义 |
|---|---|---|
| 好人领先 ≥2 | 好人轮次明显占优 | 好人：**稳住，不犯错**；狼：**必须做一次搏命** |
| 轮次持平 | 1:1 | 双方都不能失误；好人优先保神，狼优先刀神 |
| 狼领先 | 狼刀在前 | 好人：**必须使用技能抢轮次**（女巫双药、猎人开枪）；狼：**不要救人，正常刀神** |

**狼刀领先时的铁律**（多人资料反复强调）：
> 平民**不要穿神的衣服**。平民应尽力表水 + 找狼，没必要穿神牌挡刀。因为平民被刀的损失是 −1 轮，神牌被刀是 −2 轮，而穿神牌会把自己变成焦点位、被优先攻击。
>
> 狼人在狼刀领先时**才会出来悍跳非预言家的神牌**钓鱼找神（狼王守卫局适用）。

### 分类 3：焦点位在哪

焦点位 = 当前场上被最多人质疑 / 站错边 / 需要给身份的玩家。
- 焦点位在**好人**：狼队已领先 → 狼队推进。
- 焦点位在**狼**：好人正在推进 → 好人应立刻归票。
- **没有焦点位**（所有人都在划水）→ 强制建立基线：预言家归票，或神牌跳出。

## 第 3 章 · 狼人篇（每个夜晚）

> 狼人夜间决策的核心问题只有一个：**今晚这一刀，是否能最大化「轮次差 + 身份暴露度 + 信息抑制」的组合收益？**

### 3.1 首夜刀法决策树（最关键的一夜）

```
首夜刀谁？
│
├─ 【原则0】永远不要刀"自刀骗药"以外的无收益自刀
│
├─ 候选人：预言家 / 女巫 / 猎人 / 平民 / 自刀
│
│   ├─ 有警徽制 + 预见家警徽流？
│   │
│   ├─ 已知真预言家位置？（通过观察/建模）
│   │   └─► 刀预言家（首夜最大收益）
│   │        理由：预言家是唯一信息源，刀掉即好人信息归零。
│   │        风险：若女巫救了 → 真预活着，白天要抗推（这正是"抗推真预"流程的开端）
│   │
│   ├─ 女巫位置未知（最高优先目标）
│   │   └─► 盲刀女巫（最高期望收益）
│   │        理由：女巫 = +2 轮的轮次放大器 + 唯一夜视。
│   │        收益拆解：
│   │          (a) 刀中女巫且无解药 → 好人直接崩盘，狼队大优
│   │          (b) 刀中女巫但女巫毒了 → 好人 −2 轮，狼队 +2 轮，仍赚
│   │          (c) 刀中女巫且女巫自救 → 轮次打平，但女巫暴露为"可能是预言家金水"，夜间仍可再刀
│   │        ⚠ 反面：若女巫被刀后盲毒好人，好人 −2 但也暴露视野；
│   │           保守局（狼队实力不足）可改刀平民求稳。
│   │
│   ├─ 猎人位置未知
│   │   └─► 优先级低于女巫（因为猎人枪需要"被毒"才能闷掉，而毒药只有一瓶）
│   │        若首夜确定能毒到猎人 → 刀猎人收益极高（闷枪 = 好人 −2 轮且无反击）
│   │        9/10 人局 3 狼配置，女巫毒到猎人概率低，故猎人优先级 < 女巫
│   │
│   ├─ 平民
│   │   └─► 【稳态刀 / 屠民局首选】
│   │        收益：好人 −1 轮，好人视角出现"无信息倒牌"，可以进入生推
│   │        代价：好人仍有预言家验人信息
│   │        何时选：① 狼队配置低 ② 需要生推局 ③ 想让真预"看起来像被刀的好人"
│   │
│   └─ 自刀（骗药）
│        └─► 【见 3.2 专节】
└─
```

### 3.2 首夜自刀骗药 —— 完整决策树

> **现代共识**：自刀骗药在**中低端局与首救率高的局**已经过时（"没有五成把握首刀女巫，不如自刀"这一老逻辑在 95%+ 女巫首夜开药的年代基本失效）。但在**特定场景**仍是强战术。

#### 自刀的三个真实目的

| 目的 | 机制 | 收益 |
|---|---|---|
| **骗解药** | 消耗女巫唯一解药 | 后续刀口无人救，直接抹掉女巫 |
| **做高自己 / 做低对手** | 自刀悍跳 → 自己的"金水"被做高，"查杀"被做低 | 反向金水 |
| **打乱坑位** | 好人牌进狼坑，狼牌反而在好人坑 | 视野污染 |

#### 自刀收益公式

```
自刀净收益 = [女巫被消耗的解药价值] + [自身身份做高幅度] − [首夜不刀真预的机会成本]
```

**注意机会成本**：自刀 = 今晚不刀任何人（真预活着）。如果狼队有把握首夜刀中真预言家，**自刀的机会成本极高**，不应选。

#### 自刀的三种变体

**变体 A：自刀悍跳预言家（发给好人金水）**
- 机制：自刀 + 悍跳 + 发**好人**金水 → 白天直接抗推真预言家 → 好人第一轮就掉信息源。
- **要求**：
  - 被查杀/被发金水的好人**必须能扛住**，且能完成"接收金水 → 站边真预 → 发言干净"的流程。
  - 女巫**必须没救**（若女巫救了，你就是银水，必须转深水打法）。
- **风险**：若好人金水扛不住直接反水，双狼暴露 = 好人大优。
- **收益**：一轮内解决真预言家。

**变体 B：自刀悍跳预言家（发给狼队友金水）**
- 机制：狼队友成为"金刚狼"（悍跳狼的好人金水），几乎打不出去。
- **要求**：狼队友发言极强。
- **风险**：一旦狼队友爆了，双狼同时崩盘。

**变体 C：自刀不上警（深水打法）**
- 机制：自刀不悍跳，伪装成被刀的好人 → 成为银水/倒牌好人。
- **要求**：
  - 女巫首夜开药救起你 → 你获得银水身份（需之后证明自己）。
  - **不能聊爆**。
  - 可以故意"挂相"（表现得像被质疑的好人），诱导状态流玩家踩自己 → 这些踩你的强好人牌极可能是女巫/猎人 → 帮狼队钓神。
- **收益**：混淆视野，狼坑位反转。

#### 自刀禁忌

| 禁忌 | 原因 |
|---|---|
| 狼刀落后时自刀 | 会再丢一个轮次，直接输 |
| 自刀 + 发查杀给好人 | 好人的"反向金水"身份被做高，推不动 |
| 自刀 + 发查杀给狼队友 | 狼队友被推 = 双狼换一狼，亏轮次 |
| 女巫明确报银水后仍自刀 | 银水已被锁定，自刀无额外收益且暴露 |
| 有把握刀真预时自刀 | 机会成本太高 |

> **自刀后（白天）的止损动作**：若自刀被救起（银水）→ 立刻变成深水狼，不再悍跳；若被刀倒牌 → 遗言里**不能自曝**，应跳一个弱身份（守卫/民）拖延时间并传递"刀口是好人"的信息。

### 3.3 第二夜及以后的刀法

```
第二夜刀谁？
│
├─ 若第一夜是「对跳局」且真预已暴露
│   └─► 优先刀真预言家（信息源）+ 女巫（轮次源）
│       ⚠ 铁律：悍跳成功后，绝不要刀真预言家
│          （真预倒牌 → 假预报出银水 → 反向金水狼几乎无敌）
│
├─ 若第一夜是「怂狼局」（真预已坐实）
│   ├─► 首选：刀女巫（抿出女巫就刀，闷掉解药 = 屠神开始）
│   ├─► 次选：刀猎人（猎人枪是好人唯一的追轮技能）
│   └─► 再次：刀平民（屠民路线）
│
├─ 若狼刀已领先
│   └─► 【铁律】不救、不自刀、不浪费机会，正面刀神
│
├─ 若狼刀落后
│   ├─► 首选：赌刀女巫（最赚）
│   ├─► 次选：刀"看起来像强神"的外置位（发言强势、有指挥感）
│   └─► 兜底：刀平民换轮次
│
└─ 空刀（不刀）
    └─► 极罕见，仅在"需要让狼队友活到白天表演"或"死循环局势"时使用
```

**第二夜刀法的核心收益公式**：
```
刀 X 的收益 = [X 是预言家] × 2轮 + [X 是女巫] × 2轮 + [X 是猎人] × 1.5轮 + [X 是平民] × 1轮
             + [X 会开出信息] 的负项
```
> 所以优先级是：**预言家 ≈ 女巫 > 猎人 > 平民**。

### 3.4 狼人白天的四类打法（角色分工）

狼队必须在**夜间就分好工**，这是狼队最关键的团队协作：

| 打法 | 定义 | 适合谁 | 核心要求 |
|---|---|---|---|
| **悍跳狼** | 跳预言家抢警徽、抗推真预 | 逻辑与发言能力**次好/最好**的狼 | 严格模仿预的三部曲（报查验 → 留警徽流 → 聊心路） |
| **冲锋狼** | 无脑站边悍跳队友，狠踩真预 | 比较"直"、情绪化、敢撕脸的狼 | **基本不能回头**，除非悍跳自己聊炸 |
| **倒钩狼** | 站边真预言家，踩自己的悍跳队友 | 沉得住气、会装好人的狼 | 目标是"预言家永不验你" |
| **深水狼** | 全程平民视角，闷声发大财 | 演技最好、最能扛的狼 | 前中期完全不出头，后期接管全场 |

> **核心思想（轮次）**：只要抗推掉真预言家，狼队轮次就领先，后面好人是否知道狼队友已不重要。所以悍跳狼的发言**必须真实、必须敢发力**，因为狼队已经没有后顾之忧了。

#### 悍跳狼的完整打法规范

**第一步：报查验（用术语，语速快）**
```
"X 金水" / "X 查杀" —— 不要说"我验的X是好人"
⚠ 必须用术语，因为狼人可能在你报完的瞬间自爆吞掉信息
```

**第二步：留警徽流（2 张标准）**
```
"警徽流先 A 后 B"
A 金水 B 查杀 → 警徽飞 A
A 查杀 B 金水 → 警徽飞 B
A B 双金水 → 撕警徽（否则另一个人会被误解）
A B 双查杀 → 警徽外置位飞（并直接告诉好人 A、B 都是狼）
```

**第三步：心路历程（为什么验他）**
```
① 验身边（陌生人局/保守）→ 验出金水可末置归票
② 验隔位（跳验）→ 可软定义中间玩家
③ 验高配（熟人局）→ 验出金水能带队，验出查杀直接断臂
```

**第四步：给一个"不需要查验的定狼" + 警徽流 + 容错位**
> 悍跳狼必须显得"已经点了 3~4 狼"，否则可信度不足。
> 结构：**1 只定死的狼 + 2 只警徽流（疑似）+ 1 只容错位**。

**第五步：顺势而为（关键高分技巧）**
> 即使你心里认为某人是狼，发言也**必须"顺势而为"**：
> - 你的金水在场外多数人保的牌 → 顺势给到好的定义
> - 你的金水/外置位多数人打爆的牌 → **尽量不要保**（因为你保 = 跟全场好人作对）
> 这会让悍跳发言"看起来比真预言家还客观"。

**第六步：审时度势（改口与不回头）**
> 悍跳狼在**警上发言阶段**基本不能回头。
> 但**警下**可以有限度地"补强"：如"我认下我的查验，但我也承认 2 号某些点值得考虑"——这类"半回头"能保住自己的同时避免被抗推。
> 完全回头的悍跳狼 = 送双狼。

#### 倒钩狼的完整打法规范

**核心目标**：让预言家觉得你是好人牌 → 预言家永远不会验你 → 他找狼坑时忽视你。

**注意事项**：
| 要点 | 说明 |
|---|---|
| 六亲不认 | 不要犹豫，不要说"我可能觉得 X 像一点点但不确定" |
| 不要聊得像晕民 | 倒钩要"笃定 + 有逻辑" |
| 让预言家帮你输出 | 说"这张牌一定是好人牌，我保了" → 让预言家去踩别人 |
| 点狼坑用 1:2 配比 | 踩 1 张狼队友（必须是预言家眼中敌意最大的那张）+ 带 2 张好人牌（发言刚的、像神牌的） |
| 绝对不要 | 把 3 张狼队友全点出来 |

**倒钩的两种变体**：
- **全倒钩** → 深水化，身份做到最高，后期接管全场。
- **阴阳倒钩** → 无脑站真预的同时"不小心"暴露狼面，做低真预身份，让好人推真预。

#### 连狼（两张狼连号）的处理

| 规则 | 说明 |
|---|---|
| 连号位置**可以提** | 前置位刚发过言，你对他印象深是正常的 |
| 隔了几个位置**不要刻意提** | 显得突兀，别人会怀疑你别有想法 |
| 站边策略 | **尽量一致**：狼队友倒钩你也倒钩，狼队友冲锋你也冲锋 |
| 理由 | 一张倒钩一张冲锋 → 一张出局后另一张也危险；一致站边 → "发言一致" = 可能一狼一好人，两张牌身份同时做高 |

#### 狼踩狼（队友互踩）

**收益必须 > 风险**：
- ✅ 适合：把狼队友踩进狼坑凑齐坑位；帮助悍跳狼打开局势；倒钩时踩狼队友赢得预言家信任。
- ❌ 不适合：只为了"装不认识"；没有逻辑线；收益不确定时。
- **被踩的狼队友必须反踩**，否则容易被怀疑是"双狼故意狼踩狼"。

#### 狼队自爆决策

```
何时自爆？
│
├─ 悍跳狼警上发言已经彻底爆了（逻辑完全崩盘）
│   └─► 自爆：吞警徽 + 抢一个夜晚（相当于刀一个好人）
│
├─ 双爆生推局：两名狼连续自爆
│   └─► 吞警徽 + 刀预言家 → 强制进入生推
│       收益：好人失去所有信息源，狼队获得"无脑活到天亮"的自由
│       代价：狼队暴露 2 只，只剩 1 只（10 人局 3 狼时极度危险）
│
├─ 好人已经全部站错边，狼队已经领先 → 【不要自爆】
│   └─► 自爆是浪费。让狼队友正常推进票型。
│
└─ 狼队友被围剿，需要"指刀"信息
    └─► 自爆 + 指刀（自爆可留遗言的房规）→ 夜间指定刀某位玩家
```

**自爆时机的收益公式**：
```
自爆收益 = [抢到的夜晚价值 = 一个好人轮次] + [吞警徽价值] + [带走的验人信息] − [暴露的狼牌数量]
```
> 若自爆后剩 1 狼（10 人局 3 狼已爆 2 狼），基本等于自杀 → **除非能保证那一刀直接屠边达成，否则不爆**。

### 3.5 狼人的"信息战"技巧

| 技巧 | 做法 | 目的 |
|---|---|---|
| **刀口不统一** | 狼队故意报不同的刀法（"我听到是 5 号"） | 制造混乱，让好人猜错刀口 |
| **做局（假刀法）** | 队友自爆时故意"自信指刀"某位好人 | 好人误以为刀口已确定，浪费防御资源 |
| **垫飞** | 故意发言爆炸、站边真预 | 让好人把你盘进真预队伍而票掉你（牺牲换视野） |
| **凿船** | 故意聊爆一点，为狼队友凑齐狼坑 | 让悍跳的"点狼"看起来合理 |
| **给容错位** | 悍跳时留 1 只"疑似但可能是好人"的牌 | 增加可信度，也给狼队友留退路 |
| **对话女巫** | 悍跳时把某好人放进警徽流，"保护他不吃毒" | 让女巫压毒，让好人以为该牌安全 |
| **反向金水** | 悍跳发查杀给好人 | 该好人身份做高 → 后期他反水/自证时打不动 |

## 第 4 章 · 预言家篇（每个夜晚 + 每个白天）

> 预言家是全局唯一的信息源，也是全局唯一"死了游戏就崩"的角色。
> **预言家的第一目标不是找出狼，而是活到把信息传完。**

### 4.1 第一夜验人决策

```
第一夜验谁？
│
├─ 陌生人局（绝大多数情况）
│   └─► 验身边（左手边或右手边）
│        收益：验出金水 → 这人可以末置归票/做队；验出查杀 → 直接打飞，零成本
│
├─ 熟人局（认识所有人）
│   └─► 验"高配"玩家
│        收益：验出金水 → 这个人能带队，好人轮次立刻回正
│        验出查杀 → 直接断狼队一臂
│
├─ 警上/警下分布考虑
│   └─► 尽量验"能影响警徽流效率"的人
│
└─ 【铁律】首验查杀时，先留警徽流再报查杀
     ⚠ 因为说出查杀号码的那一刻，狼人极可能立刻自爆，
        你就没机会留警徽流了 → 白白损失一天验人信息
```

### 4.2 警徽流（留几轮、怎么留）

**为什么必须留 2 轮？**
> 预言家若只留 1 天警徽流，第 2 晚狼人就可以先刀外置位神牌（女巫/白痴），第 2 天听完一轮发言后继续锁定神牌位置。而预言家拿警徽末置位发言，狼人可在预言家发言前自爆。留 2 天警徽流，狼人**不得不在第 2 晚立刻刀掉预言家** → 你能提前锁定狼队的目标。

**标准双夜警徽流模板**
```
"我今晚验 A，明晚验 B"
- A 金水 B 查杀 → 警徽飞 A
- A 查杀 B 金水 → 警徽飞 B
- A B 双金水 → 撕警徽
- A B 双查杀 → 警徽外置位飞（并公开 A、B 都是狼）
```

**警徽流留法选择表**

| 局面 | 留法 | 理由 |
|---|---|---|
| 你**前置位**起跳（警上早） | 双压警下 | 警下人多，双压拉票效率最高 |
| 警上 ≈ 警下人数 | 一警下一警上 | 平衡 |
| 警上人少（≤6人） | 双/三压警下 | 警下是票池 |
| 警上人多（>6人） | 一警下 + 一/两警上 | 兼顾 |
| 警下只有 1 人 | **双压警上** | 警下那 1 人大概率是狼，压他等于白压 |
| 悍跳狼在你前面 | 第一警徽流留**悍跳狼的金水** | ①验证悍跳逻辑真伪 ②若该金水是狼，你出他；③若好人，替好人洗 |
| 悍跳狼给你发查杀 | 第一警徽流**不要**留给你自己 | 留了显得心虚 |
| 首验是金水 | 同侧压一张 + 对面压一张 | 拉票 + 找狼兼顾 |
| 首验是查杀 | 优先压对面 / 警上后置位 | 扩大战果 |

**警徽流的三条铁律**
1. **必打 2 张**（不多不少）。1 张太少防不住自爆；3 张以上没人记得住。
2. **不要连着打**（避免两张相邻位都在警徽流，看起来刻意）。
3. **死了之后绝对不能临时改警徽流**——那会让好人误判，损失比不改更大。

**警徽移交优先级**：
```
验出查杀 → 警徽给上一轮的金水（或外置位明好人）
验出金水 → 警徽给该金水（优先给能带队的 / 配置高的）
双金水 → 撕徽
双查杀 → 外置位飞 + 公开双狼
```
> 警长的 0.5 票在残局可以决定胜负 → 移交时优先选**能带队**的人。

**高级技巧：警徽流"更新"**
> 预言家可用"归票时报三个号"的方式，把警徽流与归票绑定：
> "我归票 5 号，警徽流依次是 3 号、9 号"——既完成归票，又完成警徽流更新。

### 4.3 白天发言流程（预言家）

**发言顺序（关键）**
```
① 开场：我是一张好人牌 / 我是预言家
② 报查验（术语、语速快）
③ 留警徽流（先留再报查杀，或先报验人但一定要在自爆前留完）
④ 心路历程（为什么验他）
⑤ 点狼：定 1-2 只 + 警徽流疑似 + 容错位
⑥ 归票 / 安排发言顺序 / 落警徽
```

**归票策略**
- **有查杀先出查杀**（唯一铁律）。
- **两个预言家发的是金水** → 出其中之一（预言家轮次）。
- **外置位出人会 70% 出好人** → 不要在神坑未分清时出外置位。
- 归票数量：通常归 1-2 个号，归票太多会导致票型分散。
- 归票位选择：警长归票 > 女巫 > 猎人 > 金水 > 普通末置位。

**安排发言顺序的技巧**
> 预言家拿警徽时的发言顺序是**逆风翻盘的隐藏武器**：
> - **查杀先发言**，**金水末置位**（金水末置可以听完所有人的攻击后统一反驳，说服力最大）。
> - 如果你的查杀/金水不在场，优先让**身份最不好的人先发言**（早点暴露，也避免被别人带节奏）。

**预言家被质疑时的回应技巧**
> - 有人质疑"你如果是预言家为什么不去验 X" → 不要回避，给出具体的"因为我的警徽流要奔着狼去留，验 X 收益低，X 的问题我已经在发言里点了"。
> - 有人质疑"你的心路历程不合理" → 用"我首夜视角只有 X，我做这个选择是因为 Y"来回应，**不要临时改心路历程**（改心路 = 暴露）。
> - 永远不要因为一次质疑就"补一句新的信息"（比如临时说"我昨晚还验了谁"）——这是大忌，会被狼人抓"藏信息"。

### 4.4 预言家的死亡与遗言

| 死法 | 处理 |
|---|---|
| 白天被票 | 有遗言 → **遗言第一句报查验**（术语），再留警徽流，再点狼 |
| 夜里被刀 | 无遗言 → 靠警徽流传递信息；**双夜警徽流在此刻发挥价值** |
| 夜里被刀 + 女巫救了 | 安全；但如果第二天被抗推，遗言必须报双夜验人 |
| 狼人自爆吞掉你的信息 | 你已经报过的信息已公开，未报的验人作废 → **下一轮必须重新报** |

**预言家倒牌后的最高价值动作**：
> 即使你死了，你留在警徽流里的信息仍然是好人唯一的逻辑支点。所以：
> - 被刀死 → 一定要让警徽落到"你相信的好人"手上（移交或撕徽的规则必须**事前**在发言中说过）。
> - 被票死 → 遗言要**先报验人，再留警徽流，再点狼**（顺序不能乱）。

### 4.5 预言家各回合的"不要做什么"

| 禁忌 | 后果 |
|---|---|
| 先报查杀再留警徽流 | 狼自爆 → 少一天验人信息 |
| 临时改心路历程 | 被抓"藏信息/心虚"，直接崩 |
| 因为被质疑就临时多报一张验人 | 同上，且会被认为是编的 |
| 归票时归太多号 | 票型分散，狼队绑票成功 |
| 死亡后警徽乱飞 | 好人误判信息，团队崩溃 |
| 首验查杀时不去压对面 | 浪费轮次优势 |

## 第 5 章 · 女巫篇（每个夜晚 + 每个白天）

> 女巫是全局唯一的"轮次放大器"和"夜视"。
> **女巫的第一目标不是毒对狼，而是活到能起跳带队的那天。**

### 5.1 第一夜：救还是不救？（全局最重要的一次决策）

#### 核心结论

> **在标准 9/10 人局（3 狼 3 神 3~4 民）中，女巫首夜应当使用解药救人（除自己被刀且不能自救外），这是轮次最优解。**

#### 完整决策树

```
第一夜，刀口是 X，我是否用解药？
│
├─ X = 我自己（女巫被首刀）
│   ├─ 房规允许首夜自救 → 【自救】（无条件）
│   ├─ 房规不允许自救 → 【不救】
│   │   ├─ 第一晚禁止开毒 → 什么都不做，遗言时强调"我是女巫，首夜被刀，
│   │   │   │   我没救也没毒，因为我不能让好人因为我的一手盲毒崩盘"
│   │   └─ 若允许首夜开毒 → 【盲毒】：选你听感最像狼的一张
│   │       收益：① 可能毒掉真狼 ② 自证身份，防止后续被穿衣服 ③ 加速游戏

### 5.2 毒药使用决策（第二晚起）

> 毒药是全局唯一"主动改变轮次"的技能，也是全局唯一"可以误杀好人"的技能。
> **毒药的价值 = 1 轮（毒狼）/ −2 轮（毒好人），但还有"信息价值"与"身份暴露价值"。**

#### 毒药使用的四条原则

1. **不盲毒**：没有任何信息来源时开毒 = 纯赌博。至少要有 1 条独立信息（查杀、对跳破绽、投票行为、发言状态）。
2. **早毒优于晚毒**：毒药的信息价值随时间衰减。第 2 晚毒一个 50% 狼，比第 4 晚毒一个 90% 狼更划算。
3. **毒狼有额外收益**：毒掉一只狼 = +1 轮 + 好人 +1 张视野 + 女巫威信建立（后续带得动队）。
4. **毒神/毒民的代价要算清**：毒掉预言家 = 好人 −2 轮 + 信息源永久损失；毒掉猎人 = 好人 −2 轮（且猎人闷枪）。

#### 毒药目标优先级表

| 目标 | 收益 | 条件 |
|---|---|---|
| **悍跳狼**（对跳预言家） | +1 轮 + 摧毁灭言体系 | 前提：已确认他被真预发过查杀（反向查杀） |
| **被真预发查杀的狼** | +1 轮（双杀铁狼） | 有查杀信息时，几乎必毒 |
| **对跳女巫** | +1 轮 + 防止双药被抢 | 有对跳时 |
| **发言明显爆的冲锋狼** | +1 轮 + 威慑 | 需要 ≥60% 确信度 |
| **悍跳狼的好人金水** | 0 轮 | ❌ 除非 100% 确定（否则毒好人金水 = −2 轮 + 预言家权威崩塌） |

#### 毒药使用时机决策树

```

│

│   └─► 【毒】（几乎无脑毒，收益 +1 轮）

│   └─► 【看轮次】
│       ├─ 好人领先 ≥2 轮 → 【不毒】。你不需要冒险，让白天推。

│   └─► 【不毒】。留着。盲毒的期望是负的。

### 5.3 女巫的白天打法

**关键要素**：
1. **先报银水**（这是女巫最硬的牌）。
2. **明确还有毒**（这是威慑，能让好人统一票型）。

## 第 7 章 · 平民篇（每个白天）

> 平民是好人阵营的**基数**，也是狼队最容易利用的"填充物"。
> 平民的核心任务只有两个：**① 不被抗推；② 站对边、投对票。**

### 7.1 平民的发言三步走

```
第一步：开头 —— "首先我是一张好人牌"
        ⚠ 必须坚定，不犹豫，不省略。这句话是心理暗示，也是锚点。

第二步：观点 —— 先说结论
        类型：
        · "我认为 X 号是狼"
        · "我认为 X 号像狼人牌（不确定）"
        · "我想站边 Y 号预言家"
        · "我无法站边"（但必须展开说明，不能只说一句）
        "我无法站边"的完整表达：
          1) 我无法站边
          2) 评价前置位预言家（验人还好 / 警徽流不满意 / 某点值得肯定）
          3) 说明我还没听到后置位发言
          4) 提出具体问题请对方回答
          5) 提问要具体："为什么边角位验出一张查杀还要去验边角位？"

第三步：理由 —— 展示逻辑过程
        ⚠ 绝不能先说推论最后才说结论。顺序错了别人会记不住你的逻辑。
```

### 7.2 平民的核心工作：表水

> **表水的本质**：让场上其他人（尤其是归票位）相信你是好人。

**民牌表水四要点**：
1. **站边明确** + 站边理由（哪怕站错边，也要站得真诚清晰）。
2. **点评具体**：不重复别人的话，指出具体的矛盾点、状态起伏、行为不一致。
3. **提供增量信息**：你注意到了什么别人没注意到的事。
4. **态度阳光**：不情绪化、不贴脸、不骂人。

**被质疑时的回应套路**：
| 质疑类型 | 回应 |
|---|---|
| "你发言像狼" | 聊你当初的**心路历程**（为什么当时会那样判断），而非辩解"我不是狼" |
| "你投了匪票" | 同样聊心路历程：为什么当时觉得他是狼、当时的信息是什么。⚠ 变票是硬伤，"投票比发言真实" |
| "你是狼故意做低某好人" | 分析局势：如果你真是狼，做低他对你有什么好处？如果你是好人，做低他有什么必要？反问回去 |
| "你被狼冲了" | 不辩解，用后续行为证明：之后你的每一票都跟好人一致 |

### 7.3 平民的站边决策

```
场上出现两个对跳预言家，我是平民，怎么站边？
│
├─ 检查「信源强度」
│   ├─ 谁有查杀？→ 有查杀的一方优先（但注意：被发查杀的人可能是反向金水）
│   ├─ 谁的警徽流更清晰？→ 更清晰的一方
│   ├─ 谁的心路历程更合理、更具体？→ 更合理的一方
│   └─ 谁的状态更自然、对全局理解更深？→ 更自然的一方
│
├─ 检查「团队结构」
│   ├─ 谁的支持者更像一个团队？→ 像团队的那边是悍跳
│   └─ 谁的支持者更分散、更像个人？→ 可能是真预
│
├─ 检查「行为」
│   ├─ 谁被质疑时的反应更一致（发言与投票不割裂）？
│   └─ 变票的人极大概率是狼（"投票比发言真实"）
│
└─ 无法分辨时
    └─► 【不要两个预言家都出】！❌❌❌
        "两个预言家都出了，那要预言家对跳的意义是什么？"
        → 正确做法：站其中一边（哪怕是软站边），或者投给"两边都攻击的外置位"，
          但**必须投一个**，绝不能弃票/两个都不投。
```

### 7.4 平民的投票纪律

| 规则 | 说明 |
|---|---|
| **票型必须铁** | 哪怕站错边，也和你的站边保持一致。"真正体现在一个人站边的只有票型" |
| **不要分票** | 分票 = 让狼队绑票成功。宁可投错，不可分票 |
| **不要压手** | 弃票/压手会直接送给狼队一轮轮次。⚠ 好人弃票 = 狼队绑票 = 好人输 |
| **跟票前先听发言** | 但已经形成的站边不要变 |
| **投票后不改口** | 变票 = 硬伤 |

### 7.5 平民在特殊局势下的操作

| 局势 | 平民该做什么 |
|---|---|
| **狼刀领先** | 铁律：**不要穿神的衣服**。全力表水 + 找狼。你被刀的损失是 −1 轮，穿神牌变焦点位后被优先攻击，损失更大 |
| **场上全是民（神都倒了）** | 全力裸打：全员亮身份/亮平民身份，建立发言基线，压缩狼坑 |
| **出现神牌对跳** | 除非你能自证，否则不要参与神牌对跳（对跳 = 你必死），除非**你确定对方是狼** |
| **你被发查杀** | **不要紧张**。场上一定有真预言家。用平静的语气表明自己的平民身份，强调"这个预言家是狼冒充的"，请求真预言家报查验，然后把票投给狼人。必要时**替代真预言家去死**，保证真预有第二天的查验 |
| **你被发了金水但不信对方** | **反水**：明确表态"我接水但不认你这个预言家"，并指出对方的问题。反水立警 = 直接跳预言家 |
| **你和真预站边一致，但没人理你** | 继续表水 + 归票（哪怕票型还没成型）。找准"顺风位"：站在正确的一边，承担"起点狼坑"的责任 |
| **你是末置位/归票位** | 你的核心任务是**统一票型**。盘出狼坑、给出唯一出票建议、明确"今天我们出 X" |

## 第 8 章 · 白痴篇（10 人板子扩展）

> 白痴 = "翻牌免死"的**自证型神牌**，是 10 人局最容易被忽视、也最容易被狼穿衣服的角色。

### 8.1 白痴的核心策略

| 阶段 | 行为 | 理由 |
|---|---|---|
| **全程** | **伪装成平民** | 白痴是所有神牌里最不容易被狼找到的牌；一旦暴露，狼会优先刀你（因为你"翻牌免死"能扛一次） |
| **被查杀时** | 判断发牌者：若发牌者是真预 → 翻牌自证并配合；若发牌者是悍跳狼 → **不要翻牌**，用平民逻辑反驳（因为翻牌=承认对面预言家可能是真的） |
| **被放逐时** | 翻牌免死，继续发言，但**失去投票权** | 这时你是一张"幽灵牌"：能发言不能投票。作用是提供视角、给好人信息 |
| **当警长时** | 若被放逐 → 必须移交或撕毁警徽（翻牌后不能继续当警长） | |

### 8.2 白痴的战术价值

- **屠神局**：白痴是最"耐打"的神牌，狼刀他要两次 → 好人拖轮次。
- **屠民局**：白痴可算平民（房规），是平民的挡刀牌。
- **反杀位**：翻牌后虽失票，但**发言权仍在** → 可以作为"预言家死后唯一的信息传递者"。

### 8.3 白痴被穿衣服时

> 狼人跳白痴通常是为了"吸收一次放逐"或"藏身份到后期"。
> 好人应对：
> - 预言家的查杀/金水可以直接锁定谁是假白痴（**预言家验过的牌说自己是白痴 → 若发牌者可信，则他是真白痴**）。
> - 假白痴的关键破绽：翻牌时间点（往往在狼队友快被推时翻）、发言视角（过度了解局势）、对跳预言家时的表现。

## 第 9 章 · 白天流程专项：发言与投票

### 9.1 白天的标准流程

```
1. 法官公布死讯 / 平安夜
2. （第一天）警长竞选环节：警上依次发言 → 警下投票 → 产生警长
   ⚠ 若有人警上自爆：单爆吞警徽（直接公布死讯进夜晚）
                       双爆吞警徽（保留上警信息，公布死讯后直接进夜晚）
3. 遗言（若规则有）：夜晚死者的遗言按顺序
4. 白天发言环节：按警长安排的顺序（或默认顺序）
   结束者 = 归票位（无警长时为末置位）
5. 放逐投票：警长 1.5 票 / 平票则进 PK 台再发言再投
6. 放逐者遗言
7. 进入夜晚
```

### 9.2 发言顺序的利用

**预言家/警长的排顺序技巧**：
| 目的 | 排法 |
|---|---|
| 快速定狼 | 查杀先发言 |
| 最大化金水说服力 | 金水末置位 |
| 打乱狼队计划 | 把"悍跳狼的金水"排在警上早置位（让好人先攻击他） |
| 防自爆 | 把"最可能自爆的人"排在中间（自爆会吞掉后面的话） |
| 保护好人 | 把站错边的好人排在狼队前面说（让他先表水） |

### 9.3 投票行为准则

| 阵营 | 投票准则 |
|---|---|
| **好人** | 票型必须铁；宁投不错；绝不弃票；绝不双投两个预言家；归票位统一票型 |
| **狼人** | **冲票**（集体投同一人）；**绑票**（狼数 ≥ 好人数时直接绑票获胜）；**压票**（建议好人弃票的同时自己冲票）；**分票**（在某人被多人质疑时提出另一个疑点，把票分散） |

### 9.4 平票处理

- 平票 → PK 台发言 → 平票者不能投票 → 其余玩家投票。
- **再次平票** → 依房规处理（常见：直接放逐某指定者 / 无效 / 重新投票）。
- **狼队视角**：平票是好事，可以"分票"制造平票，制造混乱。
- **好人视角**：平票是危险信号，说明票型未统一 → 应该反思归票是否到位。

## 第 10 章 · 特殊局型专项应对

### 10.1 怂狼局（狼不悍跳）

**特征**：真预言家首验金水，无人悍跳 → 真预言家身份已坐实。

**好人的任务变了**：从"分辨真假"变为"**压缩狼坑 + 逐个排坑**"。

**打法**：
1. 预言家全力打警徽流（**怂狼局里预言家警徽流是唯一找狼工具**）。
2. 神牌在适当时候跳出（1-2 张即可，不要一次全跳），建立归票基线。
3. 用"**坑位法**"排坑：预言家 + 金水 + 女巫 + 银水 构成"仲裁席"，剩下的牌全是狼坑候选。
4. 逐个上 PK 台：让每张狼坑牌发言、接受质询。
5. 预言家配置足够时，可以留**假警徽流**（故意留一个明显是好人的人当第一验），提高验人效率——让狼人误以为你不敢验真狼。

**狼队的打法（最难的局面）**：
1. **表水能力是命脉**：没有对跳掩护，每张狼牌都必须发言爆不出东西。
2. **优先抿女巫** → 刀女巫（闷解药）→ 刀预言家 → 打成生推。
3. **不要自刀**：怂狼局银水保障度低，自刀容易成为焦点牌，收益不大。
4. 尽量**屠民**（找不到女巫时）：刀平民，赌女巫会跳出来救人。
5. 如果真预言家放弃归票 → **末置位的狼去递话归票**，狼队友集体绑票冲掉那张好人牌 → 狼刀领先。

### 10.2 双爆生推局

**特征**：狼双爆吞警徽 + 刀死预言家 → 好人失去全部信息源。

**好人的任务**：**建立发言基线**，用纯发言找出狼。

**标准流程**：
- 第 1 天（实为第 3 天）：民牌集中表水；神牌跳出 1-2 张带队。
- 第 2 天（实为第 4 天）：**全员跳明身份裸打**（平民跳民、神牌跳神），靠发言质量与投票行为定狼。

**狼队的任务**：
- 已爆 2 狼（10 人局只剩 1 狼）→ 极危险，必须深度隐藏 + 靠投票活命。
- 优先找并刀神牌（猎人/女巫），因为你刀神后即使被推掉，狼也赢一半。
- **不要跳强神**（除非是绝境），因为裸打局面跳神 = 送靶。

### 10.3 对跳局（标准局，最常见）

**第一天白天（警上）的关键决策**：

```
真预言家 vs 悍跳狼的白天博弈
│
├─ 谁先起跳？
│   ├─ 真预先跳（前置位）→ 掌握"谁听我发言"的顺序优势 + 警徽流可以留警下双压
│   └─ 悍跳狼先跳 → 真预必须立刻对跳，不能犹豫（犹豫 = 掉气势）
│
├─ 悍跳狼的四种查验格式，各有不同的应对：
│   │
│   ├─ ① 悍跳发【警下金水】
│   │   → 收益：给狼拉票；力度/可信度最低
│   │   → 真预应对：第一警徽流去验警上（他不敢验警上才发警下金水），
│   │              同时评价"你连警上都不敢验，力度不够"
│   │
│   ├─ ② 悍跳发【警下查杀】
│   │   → 收益：给狼做身份 + 干扰好人视野（但一定要有一狼配合）
│   │   → 真预应对：第一警徽流**去验警下那张被发查杀的牌**
│   │              （他把它发查杀 = 他把你当好人验了，说明他需要你去对跳）
│   │
│   ├─ ③ 悍跳发【警上金水】
│   │   → 收益：给狼队友做高身份（金刚狼）
│   │   → 真预应对：第一警徽流**留悍跳的这张警上金水**
│   │              （验出来是好人 = 悍跳可信度低；是狼 = 直接出）
│   │
│   └─ ④ 悍跳发【警上查杀】
│      → 收益：最大（直接给真预扣帽子）
│      → 真预应对：立刻报自己的查验 + 心路历程，
│                 强调"我的查验逻辑是顺验/验身边，我的警徽流会告诉你谁真"
│
├─ 关键：**悍跳狼发查杀给好人 → 好人身份反向做高**
│   → 该好人后续会被认为是"反向金水"，狼队很难推掉他
│   → 好人可以利用这点：站真预、发言干净，狼队动不了他
│
└─ 关键：**双查杀 = 铁狼（两边都发查杀给同一人 → 该人必死）**
```

### 10.4 狼队"自刀骗药"与"女巫"的对抗局

| 局面 | 女巫最优 | 狼队最优 |
|---|---|---|
| 狼自刀悍跳发好人金水 | 救 → 银水是好人坐标（虽然是假的），白天该好人若发言好就当他是好人；若发言爆 → **第 2 晚毒他** | 若银水被毒 → 狼队立刻赚 1 轮 + 好人 −2 轮（毒+死） |
| 狼自刀悍跳发查杀给好人 | 救 → 该好人成为反向金水，狼队推不动 | 若该好人反水成功 → 双狼暴露 → 立即改变战术 |
| 狼不悍跳（怂狼局）自刀 | 救 → 银水在怂狼局要重点审视发言；若发言像狼 → 尽早毒 | 怂狼局银水保障度低，自刀容易成焦点 |

### 10.5 猎人被对跳（双猎人）

- 双方都跳猎人 → 好人不要参与"投票决定猎人真假"（因为猎人死后会开枪，对跳猎人被票出时开枪概率极高）。
- 正常处理：**跳过对跳，让预言家归票**，或者把猎人当作"待验证牌"，等预言家验。
- 假猎人的破绽：不敢公开枪徽流、对"我是猎人"没有威慑力、发言视角是"我应该死了"而不是"我如果死了会带走 X"。

## 第 11 章 · 复盘与自检清单

### 11.1 每回合自检三问

```
Q1：这一回合，我的操作改变了多少轮次？（用 0.4.1 的表算）
    → 如果是 0 或负收益，说明我在做无效操作。

Q2：我的操作暴露了多少身份信息？
    → 暴露越多，后续被针对的概率越高。
    → 权衡：暴露换来的轮次收益是否 > 暴露成本？

Q3：如果我判断错了，最坏结果是什么？
    → 毒错好人 = −2 轮；带错人 = −2 轮；站错边 = 好人崩盘。
    → 最坏结果是否可承受？不可承受 → 降低赌注。
```

### 11.2 各角色每回合行动清单

**狼人**
- [ ] 夜间：刀法是否奔着"预言家/女巫/猎人"？还是无脑刀民？
- [ ] 夜间：是否需要自刀？自刀的机会成本算过吗？
- [ ] 白天：我是悍跳/冲锋/倒钩/深水？我的队友角色分配是否清晰一致？
- [ ] 白天：我的发言是否"顺势而为"（顺着全场多数人的判断走）？
- [ ] 白天：连狼站边是否一致？
- [ ] 白天：自爆的收益公式算过了吗？

**预言家**
- [ ] 夜间：验人选择是否有心路（验身边/验高配/验隔位）？
- [ ] 白天：报查验 → 留警徽流 → 心路 → 点狼 → 归票，顺序是否完整？
- [ ] 白天：首验查杀时，是否先留了警徽流？
- [ ] 白天：警徽流是否打了 2 张、是否避开了连号？
- [ ] 白天：有没有因为被质疑而临时改心路/加信息？

**女巫**
- [ ] 夜间：首夜是否开解药（原则：是）？
- [ ] 夜间：毒药是否在有独立信息时才用？
- [ ] 夜间：毒药是早用还是囤着？晚用会贬值。
- [ ] 白天：是否应该起跳？起跳后是否报了银水 + 毒目标？
- [ ] 白天：隐藏时是否"爆神式发言"了？

**猎人**
- [ ] 白天：现在跳猎人是不是太早？
- [ ] 白天：枪徽流是否故意留了诱饵？
- [ ] 死时：带谁？对跳猎人 > 铁狼 > 深水 > 排水民。
- [ ] 死时：被毒 = 不能开枪，必须在遗言里说明。

**平民**
- [ ] 发言：开头"我是一张好人牌"说了吗？
- [ ] 发言：观点是否在理由之前？
- [ ] 发言：站边是否明确 + 有理由？
- [ ] 投票：票型是否铁？是否弃票/分票/双投预？

## 结语：理性玩家的四条信条

1. **一切决策先算轮次。** 不改变轮次的操作是无效操作（划水）。
2. **一切信息先算保质期。** 早验、早毒、早跳。信息越晚越贬值。
3. **一切行动先问最坏情况。** 毒错、带错、站错边的代价必须能承受。
4. **一切身份先问暴露成本。** 暴露换来的收益必须大于暴露带来的风险。

> **"如果一个玩家在每一回合都能说清：'我这一步改变了多少轮次、我暴露了多少信息、我的最坏情况是什么'——那他就是理性的。"**
