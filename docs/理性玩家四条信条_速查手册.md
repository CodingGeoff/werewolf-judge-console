# 理性玩家四条信条 · 速查手册

> 每回合开始，默念这四句。任何犹豫都能用它们裁决。

---

## 壹 · 一切决策先算轮次

> **不改轮次的操作 = 划水。**

### 轮次表（10人局 3狼3神4民 · 屠边）

| 操作 | 轮次 |
|---|---|
| 放逐 1 狼 | 好人 **+1** |
| 放逐 1 民 | 好人 −1 |
| 放逐 1 神 | 好人 **−2** |
| 女巫救 1 人 | 好人 +1 |
| 女巫毒 1 狼 | 好人 +1 |
| 女巫毒 1 好人 | 好人 −2 |
| 猎人带 1 狼 | 好人 +1 |
| 猎人带 1 好人 | 好人 −2 |
| 狼刀 1 神/民 | 狼队 +1 |
| 狼自刀被救 | **±0** |

### 三条必记

1. **毒错好人 = 放逐好人 = −2**，和放逐一只狼完全同价。毒药不是"稳赚"。
2. **狼自刀被救 = 0 轮**。被自刀骗药，好人没吃亏，别慌。
3. **枪是负收益**。猎人开枪 = 死1(−1) + 带1。带狼才 +1，带好人 −2 → **前期藏，别开枪**。

### 自检

```
这一步我改变了多少轮次？
├ +1 以上 → 值得做
├ 0        → 划水。想清楚为什么值得占一个发言位
└ 负       → 除非避免更大损失，否则别做
```

### 轮次领先方决定姿态

| 状态 | 好人 | 狼队 |
|---|---|---|
| 好人领先 ≥2 | **稳住，别犯错** | 必须搏命一次 |
| 持平 | 保神，别误伤 | 刀神优先 |
| 狼领先 | **必须用技能抢轮次** | 正面刀神，别救人 |

> ⚠ 狼刀领先时平民铁律：**不要穿神的衣服**。穿神 = 变焦点位 = 被优先攻击，损失更大。

## 贰 · 一切信息先算保质期

> **早验、早毒、早跳。信息越晚越贬值。**

### 信息保质期

| 信息 | 有效期 | 原因 |
|---|---|---|
| 首夜查验 | **第1天，最强** | 唯一一次确定信息 |
| 警徽流 | 2天 | 自爆会吞掉剩余信息 |
| 女巫银水 | 3天 | 之后可被盘成自刀 |
| 第2轮查验 | 中 | 局面已定 |
| 第3轮以后查验 | 弱 | 好人已被消耗，狼在暗处 |
| 发言状态 | **即时，1天** | 隔天就没人记得 |
| 票型 | 当天 | 第二天失真 |

### 三条必记

1. **发言是最易腐化的信息**。想说什么 **说完就忘**，没人会替你记三天。
2. **预言家留 2 天警徽流**（不是 1 天）。留 1 天 → 狼人先刀外置位神牌，第2天继续定位；留 2 天 → 狼人**被迫第2晚就刀你**。
3. **女巫的毒要早用**。第2晚毒一个 50% 狼 > 第4晚毒一个 90% 狼（后者可能已经晚了）。

### 顺序纪律

```
预言家：报查验 → 留警徽流 → 心路 → 点狼 → 归票
         ⚠ 首验查杀时先留流再报杀，否则被自爆吞掉
女巫：  有信息就毒 → 起跳报银水 → 给毒目标
猎人：  死了就开枪，别拖到没人记得
```

### 自检

```
这条信息什么时候会过期？
├ 今天过期 → 今天必须用
├ 明天过期 → 今天就要铺垫
└ 还早     → 存着，但别忘了它有时效
```

## 叁 · 一切行动先问最坏情况

> **毒错、带错、站错边，代价必须能承受。**

### 三个高危操作的代价

| 操作 | 赌对了 | 赌错了 |
|---|---|---|
| **开毒** | +1 轮 | −2 轮 + 威信崩 + 可能毒掉真预（直接输） |
| **开枪** | +1 轮 | −2 轮 + 可能带掉女巫/预言家 |
| **站边** | 团队成型 | 全员跟错 → **好人直接输** |

### 决策原则

1. **最坏结果 = 输** 的操作，不能在轮次领先时做。
2. **盲毒期望为负**。没有任何独立信息就开毒 = 纯赌。至少要有 1 条：查杀 / 对跳破绽 / 投票行为 / 发言状态。
3. **信息源强度决定胆量**：
   ```
   铁查杀 > 悍跳破绽 > 对跳破绽 > 50%状态 > 纯直觉
   ```
   纯直觉级别的怀疑 → 不够格开毒。
4. **可逆性检验**：这个操作做错了能补救吗？
   - 能补救（放毒给错人后还有别的牌）→ 可以赌
   - 不可补救（站错边把票型带崩）→ 保守

### 自检

```
如果我判断错了：
├ 最坏是 −1 轮 → 可以做
├ 最坏是 −2 轮 → 看我的轮次是否撑得住
└ 最坏是直接输 → 现在轮次领先吗？是 → 别做
```

### 关键区分

| 该赌 | 不该赌 |
|---|---|
| 轮次持平/落后时毒 60% 的狼 | 轮次领先时毒任何不确定目标 |
| 猎人被刀且有 70% 确信 | 猎人首夜被刀盲带 |
| 站边（必须选一边） | "两个预言家都出" / 弃票 |

> 💡 **站边的特例**：站边没有"不站"这个选项。所有人都要选一边，所以站边的期望值永远 ≥ 0；错误的代价是团队跟错，代价高但**无法规避**。

## 肆 · 一切身份先问暴露成本

> **暴露换来的收益，必须大于暴露带来的风险。**

### 暴露成本表

| 你暴露了 | 狼队会做什么 | 你的风险 |
|---|---|---|
| **预言家** | 立刻刀你 | 极高中（你是唯一信息源） |
| **女巫** | 立刻闷你 + 拿解药 | 极高中（你是 +2 轮放大器） |
| **猎人** | **把你留到最后一晚** | 高（枪废了，但你保住了枪） |
| **白痴** | 优先刀你（翻牌只扛一次） | 中 |
| **平民** | 正常刀 | 低 |

> 🔑 **猎人暴露 = 枪作废但人活着**；**猎人被刀 = 枪没了人也没了**。所以猎人该跳时才跳（被怀疑时），不该抢跑。

### 三条必记

1. **隐藏时不能"爆神式发言"**。你藏身份时却像神一样分析局势 → 隐藏失败。民牌的发言应该像民牌。
2. **暴露要一次换够**。跳出来就要拿到回报：女巫跳 = 报银水 + 给毒目标 + 威慑；预言家跳 = 报查验 + 留警徽流 + 归票。什么都不换的暴露 = 纯亏。
3. **狼队同样适用**：狼人暴露身份 = 送一条命。倒钩、深水狼的全部意义就是"不暴露 + 不被验"。

### 暴露决策树

```
我该不该跳身份？
├ 我是预言家/女巫 → 【跳】
│   └ 除非：局面尚未定型，藏起来能保到第二天拿更多信息
├ 我是猎人 → 【通常不跳】
│   ├ 被质疑/被归票 → 跳（+ 亮枪）
│   └ 神都倒了没人带队 → 跳（承担带队职能）
├ 我是平民 → 【不跳】
│   └ 除非被查杀（用平民逻辑反驳，不认这个预言家）
└ 我是狼 → 【不跳，除非自爆】
    └ 自爆 = 一次性暴露，换"抢一个夜晚 + 吞警徽"
```

### 暴露的收益必须核算

```
暴露收益 = [轮次收益] + [信息保护] + [威慑力]
暴露成本 = [被刀/被推概率 × 损失] + [后续被针对的针对性]

暴露净收益 > 0 → 才暴露
```

## 终极裁决器

当四条信条互相冲突时，按这个顺序裁决：

```
1. 会不会直接输？        → 会 → 先避免
2. 轮次是赚还是亏？      → 亏 → 不做
3. 信息过期了吗？        → 过期 → 立刻用
4. 最坏情况能承受吗？    → 不能 → 降低赌注
5. 暴露划算吗？          → 不划算 → 藏
```

### 一页纸总结

| # | 信条 | 一句话 | 常见错误 |
|---|---|---|---|
| 壹 | 先算轮次 | 不改轮次 = 划水 | 划水发言、盲毒、猎人乱开枪 |
| 贰 | 算保质期 | 早验早毒早跳 | 预言家只留 1 天警徽流、毒药囤到最后一晚 |
| 叁 | 问最坏情况 | 承受不起就别赌 | 轮次领先还开盲毒、猎人首夜盲带 |
| 肆 | 问暴露成本 | 暴露要一次换够 | 藏身份却爆神式发言、猎人抢跑暴露 |

> **"如果每一回合我都能说清：这一步改变了多少轮次、暴露了多少信息、最坏会怎样——那我就是理性的。"**
