## 第0章 这游戏在玩什么

### 一句话版本

> 有一群人在玩游戏。**其中藏着几个"坏人"**，坏人的目的是骗过大家、让好人被赶出去。
> 好人的目的找出坏人、把他们赶出去。

### 举个例子

想象教室里坐了 10 个小朋友。
其中 **3 个是"坏蛋"**，他们自己知道，另外 7 个是好人（**只有好人里有特殊能力的人知道事情**）。

坏蛋每天晚上商量好，**一起"叫走"一个好人**（游戏里叫"刀"）。
白天所有人开始讨论、互相怀疑、投票。
**票最多的那个人被赶出去**，永久离场。

- 如果坏蛋全被赶出去 → **好人赢**
- 如果坏蛋把"特殊能力的人"全杀了，或把"普通好人"全杀了 → **坏蛋赢**

### 为什么要"藏身份"

因为如果好人知道谁是坏蛋，一票一个，游戏 3 分钟就结束了。
所以坏蛋必须**装成好人**，好人必须**用发言找出坏蛋**。

这就是这游戏全部的乐趣。

## 第1章 一夜一天怎么转

游戏一直重复这两个部分：

```
🌙 夜晚（大家都闭眼）
   ├ 坏蛋睁眼：商量今晚要"叫走"谁
   ├ 女巫睁眼：决定救不救 / 毒不毒
   ├ 预言家睁眼：查一个人是好人还是坏蛋
   └ 猎人睁眼：法官告诉他"你死了还能不能开枪"

☀️ 白天（大家都睁眼）
   ├ 第1天先选"警长"（下面会讲）
   ├ 公布昨晚谁死了
   ├ 大家轮流说话
   ├ 投票赶走一个人
   └ 赶走的人留遗言（最后的机会）
```

### 夜晚顺序（很重要）

不同版本顺序略有不同，但**最常见的是**：

```
坏蛋 → 女巫 → 预言家 → 猎人
```

> ⚠️ **一条重要规则：坏蛋先动手，女巫后动手。**
> 所以如果坏蛋昨晚已经赢了（比如杀完了最后一张好人的牌），
> 女巫再毒人也救不回来，**算坏蛋赢**。

### 白天顺序

```
① 法官公布：昨晚 X 号死了（或"昨晚平安夜，没人死"）
② 【只有第1天】选警长：想当的人先举手 → 一个个说 → 其他人投票 → 票最多的当警长
③ 遗言（如果规则允许）
④ 轮流发言（警长可以安排顺序）
⑤ 投票赶人
⑥ 被赶的人留遗言
⑦ 进夜晚
```

### 三个"特殊名词"一次讲清

| 名词 | 大白话 |
|---|---|
| **警长** | 一个"班长"，能决定大家发言的先后顺序，投票时算 1.5 票（普通票 1 票）。死后能把"班长徽章"给别人 |
| **遗言** | 死了以后还能再发言一次的机会。**被赶走的人一定有遗言；夜里被杀的只有第1夜有** |
| **自爆** | 坏蛋主动翻牌说"我是坏蛋"，然后离场，**马上进入夜晚**。相当于放弃自己换队友一个夜晚的行动 |

## 第2章 先认识你的牌

9 人和 10 人局基本一样，只是民多一张。

### 9 人局

```
坏蛋 × 3
预言家 × 1   女巫 × 1   猎人 × 1
平民 × 3
```

### 10 人局

```
坏蛋 × 3
预言家 × 1   女巫 × 1   猎人 × 1
平民 × 4
```

> 有的 10 人局会多一张**白痴**（被赶出去可以翻牌免死，但之后不能投票了）。
> 如果有，开局前一定要问清楚"白痴算平民还是算神"——这直接决定坏蛋的胜利条件。

### 每张牌是什么

| 牌 | 晚上能做什么 | 白天能做什么 | 大白话 |
|---|---|---|---|
| **平民** | 睡觉 | 说话、投票 | 普通人，靠脑子和逻辑找出坏人 |
| **预言家** | 查一个人 → 法官告诉他"好人"还是"坏蛋" | 报查验结果、带大家投票 | **唯一能验出坏蛋的人**，最珍贵 |
| **女巫** | 一瓶**解药**（救 1 个人）、一瓶**毒药**（毒 1 个人）。**一晚只能用一瓶** | 可以公开身份带队 | **手里有 2 张王牌**，好人最需要她 |
| **猎人** | 睡觉（法官会告诉他死了能不能开枪） | 说话、投票 | 死了可以**开枪带走一个人** |
| **坏蛋** | 和队友商量，杀一个人（也可以杀自己） | 说话、投票、可以自爆 | 装好人骗大家 |

### 几个必须记住的规则

1. **女巫一晚只能用药一瓶。** 救了人就不能毒人，毒了人就不能救人。
2. **女巫不能救自己**（有些版本第一天可以，看房规）。
3. **被女巫毒死的人不能开枪**（猎人）。
4. **预言家只知道"好人/坏蛋"，不知道具体是谁**（不知道对方是平民还是女巫）。
5. **坏蛋可以"自己杀自己"**（自刀），这是很常用的战术。

## 第3章 一个最重要的办法：数轮次

> 如果这份文档你只记住一件事，就记住这个：**数轮次**。

### 什么叫轮次

想象赛跑。

- **好人队** 每赶走一个坏蛋，就往前跑一格。
- **坏蛋队** 每杀一个好人也往前跑一格。

看谁先跑到终点，谁赢。

### 一张轮次表（10人局通用）

| 谁做了啥 | 好人的轮次 |
|---|---|
| 赶走一个**坏蛋** | **+1** ⭐ |
| 赶走一个**平民** | −1 |
| 赶走一个**有本事的**（预言家/女巫/猎人） | **−2** 💀 |
| 女巫**救**回一个人 | **+1** |
| 女巫**毒**掉一个坏蛋 | **+1** |
| 女巫**毒**掉一个好人 | **−2** 💀 |
| 猎人**带走**一个坏蛋 | **+1** |
| 猎人**带走**一个好人 | **−2** 💀 |
| 坏蛋杀一个好人的牌 | 好人 −0（坏蛋 +1） |
| 坏蛋杀自己、被女巫救了 | **0**（谁都没亏） |

### 三个超好记的结论

**① 毒错好人 = 赶走好人 = −2**
女巫的毒药不是稳赚的！毒对了 +1，毒错了 −2，和赶走坏蛋的收益正好抵掉。

**② 被"骗药"其实不亏**
坏蛋自己杀自己来骗女巫的解药 → 轮次是 **0**。
好人的牌没少（救回来了），解药是没了，但好人也没亏。
**所以女巫别怪自己，继续玩。**

**③ 猎人开枪是"亏本买卖"**
猎人开枪 = 他自己死（−1）+ 带走一个人。
带走坏蛋 +1，带走好人 −2。
→ **前期千万别乱开枪**，藏好等关键时刻。

### 轮次决定每个人的姿态

| 现在谁领先 | 好人该干嘛 | 坏蛋该干嘛 |
|---|---|---|
| **好人领先 2 格以上** | **稳住！别犯错！** | 必须搏命一把 |
| **打平** | 保好有本事的牌 | 优先杀有本事的牌 |
| **坏蛋领先** | **必须用技能抢轮次**（女巫用药、猎人开枪） | 大大方方杀，不用救 |

> 💡 **坏蛋领先时，平民千万别装成有本事的牌！**
> 平民被杀只是 −1，装成神牌会变成大家重点怀疑的对象，被优先攻击，亏更多。

## 第4章 狼人怎么玩

### 坏蛋团队要先分工

3 个坏蛋要像公司分工一样，各干各的活：

| 角色 | 干什么 | 适合谁 | 关键要求 |
|---|---|---|---|
| **悍跳** | 假装自己是预言家，抢警徽，把真预言家赶出去 | 说话逻辑最好的人 | 学预言家的说话套路 |
| **冲锋** | 疯狂帮悍跳队友说话，踩真预言家 | 敢撕破脸、情绪上头的人 | **不能回头**，一条道走到黑 |
| **倒钩** | 假装站真预言家这边，踩自己的队友 | 沉得住气、会装好人的人 | 目标是"真预言家永远不验你" |
| **深水** | 全程装平民，一句话都不多说 | 演技最好、最能沉住气的人 | 前期完全隐身，后期接管全场 |

> 🎯 **分工原则**：3个人最好有"1个悍跳 + 1个冲锋 + 1个倒钩/深水"，
> 不要3个人都悍跳（会被拆穿），也不要3个人都倒钩（没人帮悍跳队友了）。

### 第一晚杀谁？（最重要的决定）

```
问自己三个问题：
1. 我知道预言家是谁吗？   → 知道 → 杀他！（他死了好人就没信息了）
2. 我知道女巫是谁吗？     → 不知道 → 赌一把杀她！（她有2张牌，杀她收益最大）
3. 我是不是个新手团队？   → 是 → 杀平民最稳（保住信息，慢慢打）
```

**为什么优先杀女巫？**
女巫一晚能"救1 + 毒1" = 好人**多赚2格**。她一个人顶两个好人。
而且她手里有解药，能救预言家。

**为什么有时候杀自己？**

| 目的 | 怎么做 | 好处 |
|---|---|---|
| **骗解药** | 自己杀自己 | 女巫用了解药 → 后面没人救 |
| **做高身份** | 自己杀自己 + 假装预言家 + 说"某人是好人" | 那个人身份被做高了 |
| **搅乱局面** | 自己杀自己 + 装平民 | 好人的"好人牌"反而被当成坏蛋 |

**骗解药的自刀，有三条禁令：**
- ❌ 轮次落后的时候别自刀（会再丢一格，直接输）
- ❌ 有把握杀真预言家的时候别自刀（白白浪费一晚）
- ❌ 自己杀自己 + 说真预言家是坏蛋（那好人身份会做高，更推不动）

### 第二晚及以后杀谁

| 情况 | 杀谁 |
|---|---|
| 真预言家已经暴露了 | **杀预言家**（信息源）+ 女巫 |
| 还没对跳（"怂狼局"） | 先找女巫 → 再找猎人 → 最后杀平民 |
| 坏蛋已经领先 | **正面杀神牌，别浪费** |
| 坏蛋落后 | 赌杀女巫 > 赌杀"看起来很厉害"的外围位 > 杀平民 |

> ⚠️ **铁律：悍跳成功了，绝对不要杀真预言家！**
> 因为真预言家一死，女巫跳出来说"昨晚我救的是某某"，
> 那个被救的人身份立刻变高，坏蛋基本推不动了。

### 白天：4 种坏蛋打法

**悍跳（假装预言家）说话顺序：**

```
① 报查验（用专业词！）      →  "7号金水" 或 " "3号查杀"
                                 ❌ 不要说"我验了7号是好人"（会被自爆吞掉）
② 留警徽流（2个号码）        →  "警徽流先4后8"
③ 讲为什么验他              →  "我验他是身边人，他发言好，先验清楚"
④ 点出1-2个狼 + 留2个疑似   →  显得"我心里已经点了4只狼"
⑤ 归票（让大家投一个人）
```

**悍跳的三个高招：**
1. **顺着大方向说**。就算你心里觉得某人是狼，如果他很多人都保他，你也要跟着说得好听。→ 显得你比真预言家还客观。
2. **给"容错位"**。留1个"看着像狼但也可能是好人"的人，显得你有分寸。
3. **学真预言家，但要比他更敢**。因为坏蛋一旦成功把真预言家赶出去，就已经赢了，不用怕。

**冲锋（帮悍跳队友）:**
- 站边要**特别坚定**，最好第一个就跳出来站边。
- 狠踩真预言家：他的查验逻辑、心路历程、警徽流哪里不合理，一个一个点。
- ⚠️ 别踩得太过火（狼坑凑齐4个就太假了），轻踩即可。

**倒钩（假装站真预言家）:**
- **特别特别坚定**。说"我可能有点怀疑"就废了。
- 让预言家帮你输出：说"3号那张牌一定是好人，我保了" → 预言家就会去踩别人。
- 点狼坑按 **1:2** 来：踩 1 个狼队友（必须是预言家最恨的那个）+ 带 2 个好人牌（发言很冲的、像有本事的）。
- ❌ 千万别把 3 个狼队友全点出来。

**深水（装平民）:**
- 从头到尾不要有存在感。
- 发言就按普通平民那样：讲道理、投票跟好人一起。
- 等预言家、女巫都死了，你就是场上身份最高的人，说啥别人都听。

### 坏蛋的白字小技巧

| 技巧 | 怎么做 | 目的 |
|---|---|---|
| **票型一致** | 3个坏蛋投同一个人 | 票数集中才能把好人推出去 |
| **分票** | 有人被怀疑时，另提一个可疑的人 | 把票分散，保护队友 |
| **踩狼队友** | 倒钩时踩自己的队友 | 让真预言家信任你 |
| **垫飞** | 故意说得烂，主动被赶出去 | 牺牲自己换队友视野 |
| **假报刀口** | 队友自爆时故意说"我猜是5号被刀" | 骗好人浪费防御 |
| **故意让好人赢一票** | 让好人以为"狼也在帮我们" | 增加迷惑 |

### 什么时候自爆

```
我该不该翻牌认坏蛋？
├ 我悍跳演砸了 → 【爆】。换队友一个夜晚 + 抢走警徽
├ 我被查杀/被追问快撑不住 → 【爆】
├ 好人已经全部站错边 → 【❌ 不爆】！已经赢了，别浪费
└─ 剩1个坏蛋时 → 【极慎】。爆了等于自杀，除非这一刀能直接赢
```

## 第5章 预言家怎么玩

> 预言家是**全场最重要的人**。你一死，好人就瞎了。

### 第一晚验谁

| 情况 | 验谁 | 理由 |
|---|---|---|
| 不认识所有人 | **验身边的人**（左或右） | 验到好人就有人能带队，验到坏蛋就直接推 |
| 认识所有人 | **验最会说话的那个人** | 验到好人他能带大家，验到坏蛋直接断一臂 |
| 有讲究的玩法 | 隔一个验 | 可以"顺便定义"中间那个人 |

### 警徽流：预言家的保命符

**问题**：如果我今晚被杀了，我查到的信息就没人知道了，怎么办？

**答案**：**提前告诉大家**。

这叫"警徽流"。

```
我今晚验4号，明晚验8号。
├ 如果我死了：4号好人 → 警徽给4号
│              4号坏蛋 → 警徽给8号
└ 如果我还活着：明天直接告诉你们结果
```

**标准留法（两张）：**
```
4号金水，8号查杀 → 警徽给 4号
4号查杀，8号金水 → 警徽给 8号
4号8号都是好人 → 撕掉警徽（否则另一个人会被误会）
4号8号都是坏蛋 → 警徽随便给外面的人，并告诉大家这俩都是狼
```

**为什么必须留两张（而不是一张）？**
留一张 → 坏蛋第2晚可以不杀你，先去杀女巫，然后再慢慢找预言家 → 你白死。
留两张 → 坏蛋**被迫第2晚就杀你**，你反而安全了，而且能传出两张验人结果。

**留警徽流的小窍门：**

| 你的位置 | 怎么留 | 为什么 |
|---|---|---|
| 你第一个发言（警上早） | **两张都留警下** | 警下人多，票多，容易拉到票 |
| 你最后发言（警上晚） | 一张留警下，一张留警上 | 平衡 |
| 警上警下人数差不多 | 各留一张 | 平衡 |
| 警下只有1个人 | **两张都留警上** | 那1个人大概率是狼，留他没用 |
| 坏蛋悍跳在你前面 | 第一张留**他给的金水** | 验一下就知道他是不是真预言家 |

> ⚠️ **绝对不要两张连号**（比如留4和5），会显得很刻意。
> ⚠️ **绝对不要死到临头改口**。说了警徽流就得照做，中途改会让人怀疑你藏信息。

### 白天说话顺序（预言家）

```
① "我是预言家"（或者"我是一张好人牌"）
② 报查验（用专业词，语速要快！）
③ 留警徽流
④ 讲为什么验他（心路历程）
⑤ 点出哪些像狼
⑥ 归票：今天我们出X号
```

> ⚠️ **首验就是查杀时：先留警徽流，再报查杀！**
> 因为你一说"3号查杀"，坏蛋可能**立刻自爆**打断你，你就来不及留警徽流了，白白损失一天信息。

### 预言家怎么安排别人发言顺序（拿警徽时）

| 想达到的效果 | 谁先说 |
|---|---|
| 早点定罪 | **查杀先说** |
| 让好人压轴反驳 | **金水最后说**（听完所有攻击再统一反驳，最有说服力） |
| 保护站错边的好人 | 让好人先说 |
| 防自爆 | 把可能自爆的人放中间 |

### 被人质疑时怎么答

| 对方说 | 你怎么回 |
|---|---|
| "你为什么不验X号？" | "我的警徽流要留着找狼，X的问题我发言里已经点了" |
| "你的心路历程不合理" | "我第一晚只知道这些，我这么选是因为…"（**不要临时改心路**） |
| "你好像在藏信息" | 重复你已报过的查验，态度平和，**不要临时多报一张验人** |

> ⚠️ **大忌**：被质疑时临时说"其实我还验了谁" → 会被当成编的，直接崩。

### 你死了怎么办

| 死法 | 你能做什么 |
|---|---|
| 白天被赶走 | **有遗言**！第一句就报查验，再留警徽流，再点狼 |
| 夜里被杀 | 没有遗言 → 靠**警徽流**把信息传出去 |
| 夜里被杀但被女巫救了 | 安全，但如果第二天被赶走，遗言要报**两天**的验人 |

## 第6章 女巫怎么玩

> 女巫手里有**2张王牌**，好人阵营最需要她。**但她也最危险**——坏蛋第一个想杀的就是她。

### 第一晚：救还是不救？

**答案：救！（除非被刀的是你自己，而你不能自救）**

**为什么？**

1. **轮次算得过来**：救 = 好人多赚1格；不救 = 好人少1格。
2. **刀中神牌的概率不低**：狼第一晚刀到"有本事的牌"的概率约 3/10。刀中预言家而不救 → 好人大崩盘。
3. **就算救起的是坏蛋（骗药）**：轮次是0，**好人没吃亏**。别怕。
4. **能猜到狼的刀法**（比如你知道狼一般先刀预言家）→ 更要救。

**3个例外（可以商量不救）：**

| 例外 | 情况 | 理由 |
|---|---|---|
| 守卫被刀 | 你很确定刀的是守卫 | 守卫有盾，救了白救 |
| 猎人被刀 | 你很确定，而且你打算毒他 | 猎人被毒就开不了枪，救他能保住好人的一个轮次 |
| 你很确定刀的是坏蛋自己 | 极少见 | 直接不救更好 |

**如果你自己被第一晚刀了：**

```
我能救自己吗？
├ 能（房规允许）→ 【直接救自己】，不用犹豫
└ 不能 → 【不救】
   ├ 第一晚禁止开毒 → 什么都不做，遗言时说"我是女巫，首夜被刀，
   │                    我没用毒，因为乱毒会让好人崩盘"
   └ 可以开毒 → 【盲毒】一个你觉得最像狼的
       ⚠ 风险：毒错好人 = −2格，还可能毒掉真预言家，直接输
       ⚠ 所以：宁可"不毒+遗言自证"，也别盲毒
```

### 第二晚起：毒药怎么用

> 毒药是**唯一能主动改变轮次**的东西。但用错了也是 −2。

**什么时候该用毒：**

```
我要不要开毒？
├ 有"确定是狼"的人（被真预言家发查杀）→ 【毒】！几乎不用想
├ 有对跳（两个女巫/两个猎人）→ 【毒】假的那个（但你得能分辨）
├ 有一个"大概60%像狼"的人 → 【看轮次】
│   ├ 好人领先2格以上 → 【不毒】！你不需要冒险
│   ├ 打平 → 【不毒】。留着，第3晚可能有更确定的目标
│   └ 坏蛋领先 → 【毒】！你必须追轮次
├ 完全没想法 → 【不毒】。留着。盲毒是亏的
└ 最后一晚了 → 【毒】你觉得最像狼的。这时候不毒就必输
```

**毒谁最划算：**

| 目标 | 收益 | 条件 |
|---|---|---|
| 悍跳的坏蛋 | +1格 + 毁掉他的整套说法 | 前提是他被真预言家发过查杀 |
| 被真预言家发查杀的狼 | +1格 | 有查杀信息时几乎必毒 |
| 对跳的女巫/猎人 | +1格 + 防止被抢牌 | 能分辨真假 |
| 悍跳的好人金水 | 0格（他本来就是好人） | ❌ 别毒！毒了就 −2 |
| 平民/无辜的人 | −2格 | ❌ 除非万不得已 |

**毒药的三个原则：**
1. **别盲毒**。至少要有一条独立信息（查杀、对跳破绽、投票、发言状态）。
2. **早毒比晚毒好**。第2晚毒一个60%狼，比第4晚毒一个90%狼更划算（因为第4晚可能已经晚了）。
3. **放毒就要跳身份**。毒了不跳 = 浪费了这一格。

### 白天要不要跳出来（亮明女巫身份）

| 情况 | 跳不跳 | 理由 |
|---|---|---|
| 首夜用了药 + 场上已有两个预言家对跳 | **【跳，报银水】** | 银水能帮好人缩小范围，还能保护真预言家 |
| 首夜用了药 + 没人对跳 | **【藏】** | 没必要暴露，藏起来还能挡刀、还能抗推 |
| 你被对跳女巫了 | **【必须跳回来】** | 用银水、用药逻辑、时间线证明 |
| 你已经放毒了 | **【必须跳】** | 要建立威信让好人听你的 |

**跳女巫的说话模板：**

```
"我是女巫。昨晚X号被刀，我救了他，所以他是银水。
 我今天还有毒。
 我要毒的是Y号，因为他是悍跳狼的好人金水。
 银水X号，你好好发言，我要确认你是不是好人。"
```

**女巫的四个必记：**
1. **藏身份时不要"像神一样说话"**。你藏，却分析得头头是道 → 暴露失败。
2. **跳出来就要一次给够**：报银水 + 说还有毒 + 指出毒目标。
3. **放了毒必须跳**，否则毒药白放。
4. **被怀疑时怎么自证**：
   - "你怎么知道刀口是X" → "因为解药用掉之前我只知道被刀的人，不知道他是谁"（这本身就是证据）
   - "昨晚是平安夜，X怎么会被救" → "平安夜+有银水=逻辑自洽"

## 第7章 猎人怎么玩

> 猎人的枪是**保命的最后一招**，但**打早了就没了**。

### 猎人的核心矛盾

```
我不跳 → 坏蛋不知道我是谁 → 可能一直不杀我 → 留到最后我开枪（好）
我跳了 → 坏蛋知道我强 → 会故意拖到最后才杀我 → 但我活着还能带队
```

**关键洞察**：坏蛋**不会傻到早早杀猎人**，因为猎人死后能带走一个人。
所以坏蛋会把猎人留到最后一晚——**那时猎人已经没用了**。

### 白天的选择

| 情况 | 跳不跳 | 为什么 |
|---|---|---|
| 没人怀疑我，女巫/预言家在带队 | **【不跳】** | 藏到最后一刻才有价值 |
| 我被怀疑/要被赶出去了 | **【立刻跳】+ 亮枪** | "我是猎人，X号，如果我被赶走，我带走Y号" |
| 预言家和女巫都倒了，没人带队 | **【跳】带队** | 没人管好人，你要站出来 |
| 我是预言家的金水/银水 | 可以不跳 | 好人坐标本身就是保护 |

### 猎人的"枪徽流"（高招）

**在白天说话时就说出来：我死了会带走谁。**

这叫枪徽流。用途：

```
我嘴上说"我死了一定带走5号"，
  但我心里其实瞄准的是8号那个狼。
       ↓
  坏蛋听到我怕5号，
  就可能判断"这人是真猎人但认错人了"，
  于是不刀我 或者 专门刀我。
       ↓
  如果坏蛋刀我 → 我当场带走8号那个狼！（赚）
  如果坏蛋不刀我 → 我活着，枪还留着，继续威慑。
```

> ⚠️ 风险：如果坏蛋刀我而我带走了好人 = −2。所以**心里瞄的必须是真有把握的狼**。

### 你死了，带谁走？

**优先级（从高到低）：**

```
1. 对跳猎人（穿着你衣服的假猎人）→ 必须带！
2. 悍跳预言家 / 被真预言家发查杀的狼 → 必须带
3. 深水狼（没被查杀但发言像狼）→ 可以带
4. 实在没把握 → 带一个"发言很冲的平民" → 减少好人能投的牌（排水）
```

### 被第一晚刀了（最尴尬的情况）

| 规则 | 怎么办 |
|---|---|
| **有遗言** | 遗言里说"我是猎人"。<br>• 有60%+把握是狼 → 带他<br>• 完全没把握 → **【压枪不开枪】**（宁可少一轮，也别带错神职） |
| **没遗言** | **【必须带一个】**。否则坏蛋会有人跳猎人冒充你，把好人带沟里。<br>• 带一个"主动喊自己是平民"的高位牌（排水） |

> ⚠️ **被女巫毒死 → 不能开枪**。遗言里一定要说"我是猎人，但被毒了，开不了枪"——这句话能给好人很大帮助（说明毒你的人是谁）。

## 第8章 平民怎么玩

> 平民是好人堆里的"大多数"。你的任务只有两个：**别被赶出去** + **投对票**。

### 平民最重要的工作：说清楚自己

### 说话的三个步骤

```
第一步：开口就说"我是一张好人牌"
        （要坚定！不要吞吞吐吐，不要省掉）

第二步：先说结论（你的观点）
        例子："我认为7号是狼" / "我站边4号预言家"
        ❌ 不要先绕一大圈推理，最后才说结论——别人会记不住

第三步：再讲理由（为什么这么认为）
```

### 如果两个人都是预言家，我站谁？

**一条铁律：不能两个都赶走！**

> ❌❌❌ "我觉得两个预言家都像狼" → 这是最蠢的话，那要预言家对跳干嘛？

**怎么分辨，看这4点：**

| 看什么 | 说明 |
|---|---|
| **谁的查验更清楚** | 有查杀的一般更强（但注意：被发查杀的好人身份反而会被做高） |
| **谁的警徽流更清楚** | 说得越具体越好，"先4后8"比"我会验的"强一万倍 |
| **谁的心路历程更合理** | 为什么验他，理由讲得通的更像真 |
| **谁的状态更自然** | 谁更懂全局，谁更像预言家 |

**还有一招：看谁是"一伙的"**
站坏蛋那边的支持者，往往说话风格、关注点都很像 → 那边是坏人。
支持真预言家的人会更分散、更多样。

**实在分不清：**
- 也要**站一边**（哪怕是"软站边"，说我暂时更信谁）
- 或者投给"两边都在骂的外围位"
- **绝对不能弃票！**

### 平民的投票纪律（很重要）

| 要做 | 不做 |
|---|---|
| ✅ 全场投同一个人（票型要一致） | ❌ 分票（票分散 = 坏蛋绑票成功） |
| ✅ 哪怕站错边也跟到底 | ❌ 弃票/不投票（**弃票 = 送坏蛋一轮**） |
| ✅ 只投一个预言家 | ❌ 两个预言家都投 |
| ✅ 有查杀先出查杀 | ❌ 查杀不清不楚就先出外围位 |
| ✅ 跟预言家/女巫/猎人归票 | ❌ 自己瞎投 |

> 💡 **为什么不能分票、不能弃票？**
> 因为坏蛋 3 个人，只要凑够票就能赶走好人。
> 你不投票 = 坏蛋少一个对手，好人多送一格。

### 被查杀了怎么办（不要慌！）

```
我被说成是狼了！
├ 冷静！场上一定有真预言家
├ 用平静的语气说："我是平民，这个预言家是假的"
├ 请求真预言家报查验
├ 把票投给那个假预言家
└ 必要时：我可以代替真预言家去死，保他活到明天继续查
```

> 💡 关键道理：**"我被发了查杀"本身不证明我是狼**——因为坏蛋也会发查杀，乱给人扣帽子。
> 你的身份要靠**真预言家的验人**或**你自己干净的发言**来证明，不是靠辩解。

### 被发了金水但不认他（反水）

> 可以明确说："我接水，但我**不认你这个预言家**，因为你这里有问题…" → 这叫**反水**。
> 更狠的可以直接**反水立警**：自己跳出来说"我才是预言家"。

### 平民的四个致命错误

| 错误 | 后果 |
|---|---|
| 弃票/压手 | 坏蛋绑票，好人直接输 |
| 分票 | 同上 |
| 两个预言家都出 | 好人不推坏蛋，等于白送一轮 |
| 坏蛋领先时穿神牌 | 变焦点位被优先杀，亏更多轮次 |

## 第9章 白天怎么说话

### 所有角色发言的通用模板

```
① 我是一张好人牌（坚定地说）
② 我的观点是：___________（先说结论）
③ 理由：___________（再讲逻辑）
```

### 好人说好话的三条

| 要点 | 说明 |
|---|---|
| **讲具体的** | 不要说"3号发言很烂"，要说"3号说他是平民但又在指挥大家投人，这不像平民" |
| **提供新东西** | 不要重复别人说过的，讲你自己注意到的 |
| **态度阳光** | 不骂人、不贴脸、不阴阳怪气 |

### 坏蛋说坏话的三个假逻辑

坏蛋必须**编出假逻辑**（因为真逻辑说出来就等于自曝）：

| 坏蛋常用 | 怎么识别 |
|---|---|
| "你是狼，因为你没跟上我的逻辑" | 好人可以跟不上逻辑但结论对 |
| "真正的预言家不会这样验人" | 越挑细节越可疑 |
| "你们不觉得X很有问题吗" | 疯狂带节奏让大家怀疑好人（真预言家会这么干） |

> 💡 **识别真假的口诀**：真预言家会**给出具体信息**（查验、警徽流、验人顺序），假预言家会**给情绪**（指责、阴阳、贴标签）。
> 真的在查人的预言家，会告诉你"我接下来验谁、为什么"。

### 发言顺序上要注意的事

| 位置 | 特点 |
|---|---|
| **第一个说的** | 有优势（后面人都能听到你的），坏蛋特别喜欢第一个跳预言家 |
| **最后一个说的** | 责任最大（要归票），真预言家当警长通常最后说 |
| **中间说的** | 最容易被两边夹击，说错了很难翻身 |

## 第10章 投票怎么投

### 好人的投票

```
第一件事：跟对的人（预言家/女巫/猎人/金水）
第二件事：全票投同一个人（不要分票）
第三件事：绝不弃票
第四件事：有查杀先出查杀
第五件事：外围位先别动（狼坑没分清时出外围位，70%会出好人）
```

### 坏蛋的投票

| 招数 | 效果 |
|---|---|
| **冲票** | 3个坏蛋一起投同一个人（票数集中才能推走好人） |
| **绑票** | 坏蛋人数 ≥ 好人数时，直接投同一个 → 好人已经输了 |
| **分票** | 有人被怀疑时，另提一个可疑的人，把票打散保护队友 |
| **压票** | 嘴上说"我们别投X，投Y"，实际全投X |

### 平票了怎么办

```
平票 → 台上的人再各说一次 → 台上的人不能投票 → 其他人选
      → 如果又平票，看房规（有的重投，有的不算了）
```

- **好人**：平票说明票型没统一 → 应该反思是不是归票没做好。
- **坏蛋**：平票是好事，可以趁乱分票。

## 第11章 三种特殊局面

### 局面一：对跳局（最常见）

> 有坏蛋假装预言家 → 两个预言家对跳。

**坏蛋假预言家的4种套路，和真预言家怎么破：**

| 假预言家说什么 | 目的 | 真预言家怎么回 |
|---|---|---|
| **给警下的平民发金水** | 拉票 | 第一张警徽流去验警上的人（他不敢验警上才发警下） |
| **给警下的平民发查杀** | 搅乱好人视野 | 第一张警徽流**就验那张被发查杀的**（他把好人当好人验了，说明他需要你去对跳） |
| **给警上的人发金水** | 给狼队友做高身份 | 第一张警徽流**留他这张金水**（验出是好人说明他假，是狼直接推） |
| **给警上的人发查杀** | 直接扣真预言家帽子 | 立刻报自己的查验 + 警徽流，讲清为什么验他 |

**两个必记：**
- **"双查杀"= 铁狼**。两个预言家都说同一个人是狼 → 那个人必死。
- **"反向金水"**：假预言家给好人发查杀 → 那个好人身份反而被做高了，坏蛋很难推掉他。

### 局面二：怂狼局（坏蛋不跳预言家）

> 没人冒充预言家，真预言家身份已经坐实。

**好人要做的事**：从"分辨真假"变成"**压缩范围**"。

```
① 预言家全力留警徽流（这是唯一找狼的工具）
② 挑1-2张有本事的牌跳出来带队（不要一次全跳）
③ 用"坑位法"：
   预言家 + 他的金水 + 女巫 + 银水 = 4张确定的好人
   剩下的牌全是嫌疑人 → 一个一个上台说话接受质询
④ 预言家技术好时，可以故意"留假警徽流"骗坏蛋放松警惕
```

**坏蛋怎么办（很难打）：**
```
① 唯一出路：发言不能有破绽
② 优先找女巫 → 杀女巫（闷掉解药）→ 杀预言家 → 变成"盲打"局面
③ 找不到女巫就屠平民（赌女巫会跳出来救人）
④ 不要自刀！怂狼局里银水保障很低，自刀容易变焦点
```

### 局面三：双爆盲打局

> 坏蛋连续爆两个，把警徽搞没，还杀了预言家 → 好人啥信息都没了。

**好人要做的**：建立发言标准线。


## 第13章 记住这四句话

> ### 1️⃣ 先算轮次
> **不改变轮次的操作 = 白说。**
> 先问："我这一步能赚几格？" 答案接近0，就别花这个发言位。
>
> ### 2️⃣ 信息会过期
> **早查、早毒、早说。**
> 发言只有一天有效期，想说什么当天说完。
>
> ### 3️⃣ 先想最坏情况
> **赌错了能不能承受？**
> 毒错人 = −2格，跟赶走好人一样重。轮次领先时别赌。
>
> ### 4️⃣ 亮身份要算划不划算
> **暴露换来的好处，要大于暴露带来的危险。**
> 猎人暴露 = 枪废了但人活着；猎人被杀 = 枪和人一起没。

## 写在最后

这游戏看着是"猜谁是坏蛋"，其实比的是**谁更清醒**。

- 你要记住每一句话、每一次投票、每一个死亡顺序；
- 你要在**信息很少**的时候做出**不能反悔**的决定；
- 你要在**自己也在嫌疑中**的时候保持冷静。

练熟了这四句话——**先算轮次、算保质期、问最坏情况、算暴露成本**——你就已经赢了一半。
